Report A — Stale cards (90+ days)

Cards that haven't been pulled, moved, added, or verified in 90+ days. Worth a physical check (and a pricing review).

0 selected

Report B — High-count duplicates

Same card, same box, quantity 10 or more. Either you really have that many, or something's double-counted.

Report C — Box totals

Cards and units per box. Boxes over 800 units are flagged (typical box capacity).

Report D — Structurally broken rows

Missing name, set, number, condition, or box. These should not exist.

Report E — Unknown scan date

Cards whose box code didn't parse as a date (e.g. LOTR, NCC1701). These can't be judged for staleness. Consider adding a scanned_on value manually if you know it.

Report F — Deleted cards (recoverable)

Cards that have been soft-deleted. They're hidden from the main inventory but still in the database. Restore to bring them back.
