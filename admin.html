Seed server from CSV

Replaces the entire live inventory with the contents of the selected CSV. Use this for initial setup, or to restore from a backup. Every card in the current inventory will be removed.

Write key

The write key is stored in this browser's localStorage. Clear it if you've entered the wrong one and need to be prompted again.

Scan batches

Batches created by "Append scan batch" on the main app. A seed (above) doesn't create a batch, because it replaces rather than appends.

Click "Load batches" to load.
